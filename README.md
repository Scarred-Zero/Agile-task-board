# Agile Task Board

A responsive task board interface built with HTML, CSS, and JavaScript.

## Features

- Task board with status columns, task cards, and sprint summary metrics
- Task creation modal and activity log drawer
- Dark/light theme toggle with the selected theme saved in the browser
- Responsive layout for different screen sizes

## Getting Started

No build step or package installation is required.

1. Clone or download this repository.
2. Open `assets/html/index.html` in a browser.

For local development, open the project in Visual Studio Code and run the
`assets/html/index.html` file with the Live Server extension. The project
configures Live Server to use port `5501`.

## Project Structure

```text
assets/
  css/       Stylesheets
  html/      Task board page
  img/       Placeholder avatars
  js/        JavaScript
```
